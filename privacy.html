Google 사용자 데이터는 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을, Microsoft 사용자 데이터는 Microsoft API 이용약관을, Slack 사용자 데이터는 Slack API 이용약관을 따르며, 어느 것도 광고·범용 모델 학습에 사용하지 않습니다.
